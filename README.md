A modern, full-stack facial recognition attendance management system that leverages the latest in AI, web development, and cloud technology.

---

## ✨ Features

- ⚡ **Facial Recognition Attendance:** Fast, secure, and AI-powered attendance marking.
- 📝 **Worker Registration:** Seamless onboarding for new team members.
- 📋 **Attendance Logs:** Track attendance with easy-to-read logs.
- 🚦 **Admin Dashboard:** Manage workers, attendance, and view analytics.
- ☁️ **Cloud Database:** Data stored securely using Firebase Firestore.
- 📱 **Responsive UI:** Mobile-first, friendly on any device.
- 🔒 **Privacy-focused:** Facial data handled securely.
- 🚀 **Easy Deployment:** Hosted on Vercel for lightning-fast access.

---

## 🛠️ Tech Stack

- **Frontend:** [Next.js](https://nextjs.org/) + [Tailwind CSS](https://tailwindcss.com/)
- **Backend / Database:** [Firebase Firestore](https://firebase.google.com/docs/firestore)
- **Facial Recognition:** [face-api.js](https://github.com/justadudewhohacks/face-api.js)
- **Deployment:** [Vercel](https://vercel.com/)
